# khatzie.github.io

This site loads page content from [public/assets/data/content.json](public/assets/data/content.json) in the browser.

For local preview, serve the project over HTTP instead of opening [index.html](index.html) directly with `file://`:

```bash
cd "/Users/katherinepetalio/My Projects/Portfolio/khatzie.github.io"
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.
